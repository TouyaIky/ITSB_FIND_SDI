Panduan Penggunaan ITSB Find

Langkah singkat memakai fitur yang tersedia di aplikasi ini.

{% call step('01', 'info', 'Mengenal ITSB Find', True) %}

ITSB Find adalah platform Lost and Found untuk civitas ITSB. Kamu dapat melaporkan barang hilang, melaporkan barang yang kamu temukan, dan mencari barang di daftar. Penyerahan barang kepada pemilik selalu diverifikasi langsung oleh Satpam.

Belum punya akun? Pilih “Daftar”. Hanya ingin melihat-lihat? Pilih “Masuk sebagai Tamu”; tamu dapat mencari barang tetapi tidak dapat membuat laporan.

{% endcall %} {% call step('02', 'package-search', 'Menjelajahi Barang') %}
  1. Buka “Daftar Barang Temuan” untuk barang yang sudah diterima dan disimpan Satpam.
  2. Buka “Daftar Barang Hilang” untuk laporan kehilangan dari pengguna lain.
  3. Gunakan kolom “Cari”, kategori, lokasi, tanggal, dan status untuk menyaring hasil, lalu klik kartu barang untuk melihat detail.

Nomor telepon dan data pribadi pelapor tidak pernah ditampilkan di daftar.

{% endcall %} {% call step('03', 'search-x', 'Melaporkan Barang Hilang') %}
  1. Periksa dulu Daftar Barang Temuan, mungkin barangmu sudah ada.
  2. Buka “Laporkan Barang Hilang”, lalu isi nama barang, kategori, ciri-ciri, lokasi, tanggal, waktu, dan nomor telepon.
  3. Foto bersifat opsional (JPG, JPEG, atau PNG, maksimal 2 MB). Tekan tombol simpan.
  4. Laporan langsung tersimpan dan sistem menampilkan rekomendasi barang temuan yang mirip.

Rekomendasi hanya petunjuk, bukan penentuan kepemilikan.

{% endcall %} {% call step('04', 'package-plus', 'Melaporkan Barang Ditemukan') %}
  1. Buka “Laporkan Barang Temuan”, isi data barang, lokasi, tanggal, dan waktu.
  2. Unggah foto barang (wajib) dan isi nomor telepon, lalu kirim laporan.
  3. Serahkan barang secara fisik ke pos Satpam.
  4. Setelah Satpam mengonfirmasi penerimaan, barang tampil di Daftar Barang Temuan.
{% endcall %} {% call step('05', 'clipboard-list', 'Memantau Laporan') %}
  1. Buka “Laporan Saya” untuk melihat semua laporanmu beserta statusnya.
  2. Status barang temuan: Menunggu Penyerahan, Belum Dikembalikan, Sudah Dikembalikan, atau Ditolak.
  3. Status barang hilang: Belum Ditemukan, Selesai, atau Ditolak. Jika laporan ditolak, alasannya ditampilkan di halaman yang sama.
  4. Jika barangmu sudah kembali, tekan “Sudah ketemu” pada laporan kehilanganmu.
{% endcall %} {% call step('06', 'hand-helping', 'Proses Pengambilan Barang') %}
  1. Jika barangmu ada di Daftar Barang Temuan, datang ke pos Satpam.
  2. Bawa identitas dan bukti kepemilikan, misalnya foto lama barang atau ciri khusus yang tidak tampak di daftar.
  3. Satpam memverifikasi kepemilikanmu, mendokumentasikan serah terima, lalu mengubah status barang menjadi “Sudah Dikembalikan”.
{% endcall %} {% call step('07', 'message-square-text', 'Kritik dan Saran') %}
  1. Buka “Kritik dan Saran”, pilih kategori, isi subjek dan pesan, lalu kirim.
  2. Jika kamu masuk dengan akun, status tindak lanjut masukanmu tampil di halaman yang sama.
{% endcall %}
